# Design Portfolio

Thư mục này chứa các tài liệu thiết kế đóng gói để sử dụng bên ngoài dự án — chủ yếu phục vụ mục đích ứng tuyển, pitch nội bộ hoặc showcase.

## Files

### `falcon-intern-portfolio.md`

Portfolio gửi kèm CV khi ứng tuyển **Game Designer Intern** tại Falcon Game Studio (dòng Puzzle). Định dạng Markdown thuần, có thể:

- Đính kèm trực tiếp vào CV (Falcon chỉ nhận 1 file đính kèm qua hệ thống auto-screening).
- Convert sang PDF qua bất kỳ Markdown editor (VS Code, Typora, Obsidian).
- Render thành 8-10 trang.

**Khác với GDD master ở chỗ:**

- Tone persuasive cho nhà tuyển dụng, không phải tài liệu nội bộ.
- Showcase 3 hệ thống có tính logic nhất (Risk, Chain, Schedule) thay vì liệt kê đầy đủ 12.
- Có phần "Tại sao Falcon?" phân tích game của họ.
- Trung thực về Phase 1 và 0/72 task done.

## Cách sử dụng

1. **Cho ứng tuyển:** Gửi `falcon-intern-portfolio.md` đính kèm CV theo hướng dẫn của nhà tuyển dụng (hyperlink hoặc QR code).
2. **Cho pitch:** Sử dụng GDD master (`design/gdd/farm-horror-gdd.md`) — đầy đủ và chi tiết hơn.
3. **Cho onboarding:** Contributor mới nên đọc GDD master trước, portfolio không đủ depth để onboard.

## Cập nhật

Mỗi khi GDD master cập nhật, kiểm tra xem portfolio có cần sync số liệu (số task done, autoload mới, scene mới) không. Tone và cấu trúc portfolio thường ổn định hơn GDD.
